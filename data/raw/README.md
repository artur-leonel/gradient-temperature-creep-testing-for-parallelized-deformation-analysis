# Raw inputs

Place files relative to the repository root:

| Path | Contents |
|------|----------|
| `dic_mat/strain.mat` | Variable `strain` — DIC creep strain |
| `dic_mat/temperature.mat` | Variable `temperature` — DIC temperature |
| `workbook/main.xlsx` | Sheets `CCT *`, `ΔT *`, `Manual_*`, `all_data`, etc. |

Large `.mat` files: Git LFS or an external data repository with a DOI cited in the Data Availability statement.
