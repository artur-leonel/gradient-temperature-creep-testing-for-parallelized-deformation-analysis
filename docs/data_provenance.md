## Source Documents and Context

The analysis package does **not** include a manuscript PDF. Context for methods and reported numbers comes from the Word files in the **`TMS 2025`** project folder (one level above `Python/`), i.e. relative to this repo root:

- Manuscript (Word): `../../Parallelized Creep Testing Using Temperature Gradients for Efficient Deformation Analysis.docx`
- Supplementary Information (Word): `../../Supplementary Information.docx`

Exported PDFs of the manuscript are optional and not used by the pipeline.

- Key reported workflow behavior in manuscript/supplement:
  - Raw creep curves are culled using ASTM-oriented filters.
  - Culling factors include edge buffer, creep activation temperature, temperature stability, and isotherm grouping.
  - Reported progression: large raw set (13,462) reduced to ASTM-valid subset (474).

## Processed Data Policy

- This package does not ship a separate `data/processed/` dataset.
- Processed/derived data are generated by the workflow under `results/published/` (journal bundle) and `results/workflow_exports/` (intermediate tables). See `results/README.md`.
- This keeps the repository aligned with the paper inputs and avoids duplicate intermediate artifacts.

## Code Trace of Data Usage

Primary executable:
- `python_workflow.py`

Observed read patterns:
- `sio.loadmat('data/raw/dic_mat/strain.mat')`
- `sio.loadmat('data/raw/dic_mat/temperature.mat')`
- `pd.read_excel('data/raw/workbook/main.xlsx', ...)`
- `pd.read_excel('data/raw/workbook/main.xlsx', sheet_name=f'Manual_{temp}')`

Main transformation steps:
1. Load full-field strain/temperature arrays.
2. Apply area trimming with edge buffer.
3. Apply temperature activation threshold.
4. Apply ASTM temperature stability filtering.
5. Group into isotherm bands and remove sparse/invalid groups.
6. Compute MCSR/Arrhenius/activation-energy outputs.
   - Python Delta-T uses filtered full-field DIC curves.
   - Manual Delta-T uses curated `E*` channels from `ΔT` sheets and computes both MCSR slope and representative temperature on the same analysis window.
   - CCT reported activation energy fit uses the 550/575/600C points to match manuscript reporting.
7. Produce figure/table artifacts.

## Source_Data.xlsx — what is large and what is optional

Built by `export_source_data_workbook()` after a full run. Intended as **numeric backing for Python-generated figures**, not a dump of the entire raw workbook.

| Region | Role | Size drivers |
|--------|------|----------------|
| `arrh_buf_*`, `spatial_pts_b*` | One sheet per edge buffer in `SOURCE_DATA_EDGE_BUFFERS` (`constants.py`). Matches Arrhenius / spatial / activation-energy-vs-buffer sweeps. | Row counts drop as buffer increases (fewer valid spatial points). |
| `all_techniques_points` | Overlay points for CCT vs manual vs Python ΔT. | Moderate. |
| `manual_DT_long` | Long-format time–strain for **paper-curated** manual `E*` channels only (not the whole Excel). | ~10⁴ rows; scales with channels × time points. |
| `temperature_groups` | Long-format copy of the `all_data` slices used for the temperature-group figure. | ~10⁴–10⁵ rows from 8 groups × extensometers × time. |
| `creep22_*` | Duplicate of `results/published/creep_curves_data.xlsx` (Metadata + `Temp_*` isotherm sheets). | Often **most of the file size**: dense isotherms (e.g. 600 °C) export **every** curve column used in creep figures (5 °C grouping). |

**Optional slimming (same numbers, smaller Source_Data):** in `src/pipeline/constants.py`, set `SOURCE_DATA_EMBED_CREEP_ISOTHERMS = False`. Creep isotherm tables then stay **only** in `results/published/creep_curves_data.xlsx`; the `About` sheet records that link. Re-run `python -m src.main run` (or call `export_source_data_workbook()` after the pipeline) to regenerate.

**Raw input `data/raw/workbook/main.xlsx`:** the pipeline reads only the sheets listed in `docs/data_sources.md`. Other tabs (e.g. scratch / graphs) are **not** read at runtime; you may distribute a trimmed copy for deposit if you want a smaller raw bundle.

## Reproducibility and Validation Notes

- Workflow execution command: `python -m src.main run`
- Image parity command: `python -m src.main verify-images`
- Matplotlib SVG output includes a metadata timestamp; consecutive runs may not be byte-identical even when plots are visually the same. `svg.hashsalt` is set in `set_plot_style()` to stabilize clip-path identifiers.

- The CLI (`src/main.py`) runs the same `workflow.main()` as `python_workflow.py`.
- Canonical inputs are under `data/raw/`; derived files go to `results/published/` and `results/workflow_exports/` (no pre-shipped `data/processed/`).
